FleetFinch

A software suite designed to bring modern functionality to iOS 9.3.5 and iOS 9.3.6 devices

Installation Steps

  1. Use Carbon to install the Carbon jailbreak on your device
  2. After Carbon has successfully been installed, open the Cydia app that you now have on the home screen.
  3. Wait for packages to automatically refresh and update. Choose "Complete Upgrade" if prompted. You can manually refresh the software sources as well by navigating to the Sources page.
  4. Navigate to the Search page and search "iocaste untether". iocaste untether is an untethered jailbreak and system package created by staturnz for 32-bit iOS devices running iOS 9.3.5 or iOS 9.3.6.
